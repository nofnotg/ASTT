V6.6 BTC Dominance 데이터 품질

BTC Dominance는 매수 신호가 아니라, 알트 시장이 위험해지는지 확인하는 별도 overlay입니다. 기존 Rolling/Balanced 기준선은 수정하지 않았습니다.

안전 고정: 모든 결과는 PAPER 모의투자입니다. 실제 주문, 주문 테스트, 취소, 출금은 사용하지 않았고 real_order_enabled=false, live_order_allowed=false입니다.
